# Sushi Go - deck composition

*Submitted rule material. The rulebook lists these counts under CONTENTS; they are
repeated here in a form the compiler can read directly, alongside the rules themselves.*

*What each card **does** is deliberately NOT in this file. Card effects are learned at
the table, one card type at a time, as they actually appear - that is the whole point of
Phase 5. The module must look effects up in the catalog, never hardcode them.*

## Two-player setup

Deal **10 cards to each player**. The remainder stays in a face-down pile and is not used
during the round. The game runs over **3 rounds**.

## Categories

Some effects refer to groups rather than single types. The groups are:

- **nigiri**: `salmon_nigiri`, `squid_nigiri`, `egg_nigiri`
- **maki**: `maki_1`, `maki_2`, `maki_3` - and note these differ in how many icons they
  contribute, which is what a majority comparison counts rather than the card count

## What is deliberately absent

No scoring values appear here. A module compiled from this file plus the rulebook knows
the *structure* of the game - how many cards, how a turn works, when a round ends - and
knows nothing about what a tempura is worth until somebody says so.
